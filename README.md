# Diplom_2
## Автотесты для API сервиса Stellar Burgers
Stellar Burgers — это онлайн-сервис, позволяющий собирать и заказывать бургеры из необычных ингредиентов.

### Структура проекта
- tests — папка с тестами.
- conftest.py — содержит фикстуры. Здесь создаются временные пользователи
- helpers.py — вспомогательные функции для генерации тестовых данных
- data.py — хранит тестовые данные, используемые в запросах.
- urls.py — содержит адреса API и конкретных эндпоинтов сервиса.
- allure_results — директория с результатами тестов.
- requirements.txt — список всех зависимостей, необходимых для запуска тестов.
- README.md — текущий файл, объясняющий структуру и назначение проекта.

### Описание проверяемых сценариев
Тесты покрывают ключевые сценарии использования API, согласно заданию:

- test_user_registration.py
Проверяет регистрацию пользователя
- test_user_login.py
Тестирует авторизацию
- test_update_user.py
Проверяет обновление данных пользователя
- test_create_order.py
Исследует создание заказа
- test_get_order.py
Проверяет получение списка заказов

### Установите зависимости
`pip install -r requirements.txt`

### Запустите все тесты
`pytest -v`

### Генерация отчета Allure
После запуска тестов вы можете посмотреть отчёт в удобном веб-интерфейсе:

`allure serve allure_results`
